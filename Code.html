Mathematical Formulation

The scheduling engine formulates match decision variables $x_{t,s,r,k} \in \{0,1\}$ where binary choice corresponds to assigning tutor $t$, student $s$, room $r$, at discrete timeslot $k$.

// Objective Function
$$\max \sum_{t,s,r,k} (P_{s,t} \cdot x_{t,s,r,k}) - \lambda \sum_{r,k} \text{Overcap}_{r,k}$$
// Subject to hard room & availability constraints
$$\sum_{s,r} x_{t,s,r,k} \le 1, \quad \forall t, k$$
